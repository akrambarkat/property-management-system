# 📘 دليل مشروع EMAARPlus

## كيفية استخدام هذا الدليل

هذا المجلد هو **المرجع الأساسي** لكل AI Agent يعمل على المشروع. كل ملف مخصص لـ Agent معين أو جانب من المشروع.

### الترتيب الصحيح للقراءة

1. `01_SRS.md` — افهم المتطلبات كاملة
2. `02_ARCHITECTURE.md` — افهم هيكلة النظام
3. `05_DESIGN_SYSTEM.md` — تعرف على التصميم والخطوط والألوان
4. `09_DATABASE_AGENT.md` — ابدأ بقاعدة البيانات
5. `06_BACKEND_AGENT.md` — ثم الباكند
6. `07_WEB_AGENT.md` — ثم الويب
7. `08_MOBILE_AGENT.md` — ثم الموبايل
8. `10_DEPLOYMENT_AGENT.md` — وأخيراً الرفع

### لكل Agent ملفه الخاص
| الملف | لمن؟ |
|-------|------|
| `06_BACKEND_AGENT.md` | Agent الباكند (Laravel) |
| `07_WEB_AGENT.md` | Agent الويب (Vue.js) |
| `08_MOBILE_AGENT.md` | Agent الموبايل (Flutter) |
| `09_DATABASE_AGENT.md` | Agent قاعدة البيانات |
| `10_DEPLOYMENT_AGENT.md` | Agent الرفع على الهوست |

### الخطوط
موجودة في مجلد `fonts/` — انسخها لمشروعك المحلي عند الحاجة.

### العملة
النظام يدعم 3 عملات: **شيكل (افتراضي) — دينار — دولار**.
تتغير من صفحة الإعدادات.

---

> **ملاحظة:** هذه المحادثة هي المسؤولة عن التخطيط. أي Agent جديد يقرأ هذا الدليل أولاً قبل أي شيء.
